# Analog Clock (HTML, CSS & JavaScript)

An **interactive analog clock** that advances time when you click it, built using **HTML**, **CSS**, and **JavaScript**.

---

##  Functionality & Features

- **Live Time Display** – Shows the current time via moving hour, minute, and second hands.
- **Interactive Click-to-Advance** – Clicking anywhere on the clock speeds it up or advances the time by a specific increment.
---

##  File Structure
Analog_Clock_By_Using_JS/
├── index.html # Defines the analog clock structure and click interaction
├── style.css # Styles the clock face, hands, and responsive layout
├── script.js # Handles clock time updates and click-based advancement
